# เฉลยคำถามวิเคราะห์และสรุปผล Lab 15

## ตอนที่ 19: คำถามวิเคราะห์หลังปฏิบัติ

19.1 **โครงงานที่พัฒนาช่วยแก้ปัญหาใด**
ตอบ: ช่วยแก้ปัญหาการลงทะเบียนเข้าร่วมกิจกรรมของนักศึกษาที่เดิมใช้วิธีการกรอกเอกสารหรือแบบฟอร์มภายนอก ซึ่งเกิดปัญหาข้อมูลซ้ำซ้อน ตรวจสอบจำนวนผู้สมัครได้ยาก และสรุปรายงานชั่วโมงกิจกรรมล้าช้า

19.2 **กลุ่มผู้ใช้งานเป้าหมายของระบบคือใคร**
ตอบ: นักศึกษา (ลงทะเบียนกิจกรรมและเช็ครายละเอียด) และผู้ดูแลระบบ/เจ้าหน้าที่ (จัดการสร้างกิจกรรม แก้ไขข้อมูล และดูรายชื่อผู้ลงทะเบียน)

19.3 **ฟังก์ชันหลักของระบบมีอะไรบ้าง**
ตอบ:
- หน้าภาพรวม Dashboard สรุปสถิติกิจกรรม
- ระบบค้นหาและกรองกิจกรรมตามหมวดหมู่/สถานะ
- ระบบลงทะเบียนนักศึกษาพร้อมตรวจสอบข้อมูลซ้ำและรหัสนักศึกษา
- ระบบ CRUD จัดการกิจกรรมสำหรับผู้ดูแลระบบ

19.4 **นักศึกษาใช้ React Component ใดบ้าง และแต่ละ Component มีหน้าที่อะไร**
ตอบ:
- `Navbar`: แถบเมนูนำทางระหว่างหน้า
- `ActivityCard`: การ์ดแสดงผลรายละเอียดกิจกรรมแต่ละรายการ
- `RegisterModal`: ฟอร์มลงทะเบียนเข้าร่วมกิจกรรมของนักศึกษา
- `ActivityFormModal`: ฟอร์มสำหรับเพิ่มหรือแก้ไขข้อมูลกิจกรรม

19.5 **ระบบใช้ State จัดการข้อมูลส่วนใดบ้าง**
ตอบ:
- `activities`: รายการข้อมูลกิจกรรม
- `search` / `selectedCategory`: ข้อความและตัวกรองการค้นหา
- `activeTab`: หน้าจอที่กำลังแสดงผล
- `registeringActivity` / `editingActivity` / `detailActivity`: สถานะ Modal ที่เปิดอยู่

19.6 **ระบบใช้ Form และ Validation อย่างไร**
ตอบ:
- ฝั่ง Frontend ตรวจสอบรหัสนักศึกษาต้องเป็นตัวเลข 10-11 หลัก และตรวจสอบการกรอกข้อมูลครบถ้วน
- ฝั่ง Backend ตรวจสอบที่นั่งคงเหลือ ป้องกันการลงทะเบียนเกินจำนวน และเช็ครหัสนักศึกษาซ้ำในกิจกรรมเดียวกัน

19.7 **ระบบใช้ API Endpoint ใดบ้าง**
ตอบ:
- `GET /api/activities`
- `GET /api/activities/:id`
- `POST /api/activities`
- `PUT /api/activities/:id`
- `DELETE /api/activities/:id`
- `POST /api/registrations`
- `GET /api/registrations/activity/:activityId`

19.8 **ฐานข้อมูลของระบบประกอบด้วยตารางใด และแต่ละตารางเก็บข้อมูลอะไร**
ตอบ:
- ตาราง `activities`: เก็บรายละเอียดกิจกรรม เช่น ชื่อ หมวดหมู่ วันเวลา สถานะ จำนวนรับ
- ตาราง `registrations`: เก็บข้อมูลนักศึกษาที่ลงทะเบียน และเชื่อมโยงกับกิจกรรมด้วย `activity_id`

19.9 **ปัญหาสำคัญที่สุดที่พบระหว่างพัฒนาคืออะไร และแก้ไขอย่างไร**
ตอบ: ปัญหาข้อมูลผู้ลงทะเบียนเกินจำนวนรับเมื่อมีคนกดลงทะเบียนพร้อมกัน แก้ไขโดยใช้ Database Transaction และ row locking (`FOR UPDATE`) ใน SQL Query

19.10 **หากมีเวลาพัฒนาต่อ จะเพิ่มหรือปรับปรุงฟังก์ชันใด**
ตอบ: เพิ่มระบบเข้าสู่ระบบ (Authentication) สำหรับนักศึกษาและผู้ดูแลระบบ, ระบบสแกน QR Code สำหรับเช็คชื่อเข้างาน, และระบบส่งอีเมลยืนยัน

19.11 **ความรู้จากบทที่ 1–14 ถูกนำมาใช้ในโครงงานอย่างไร**
ตอบ: ประยุกต์ใช้ JSX, React Components, State management (`useState`, `useEffect`), Form validation, REST API Design, Node.js + Express, และ MySQL Database

19.12 **สิ่งที่ได้เรียนรู้จากการทำโครงงานนี้คืออะไร**
ตอบ: เข้าใจกระบวนการพัฒนาเว็บแอปพลิเคชันแบบ Full Stack ตั้งแต่ขั้นตอนการออกแบบ Database, API, UI Component จนถึงการต่อเชื่อมและการทดสอบระบบจริง

## ตอนที่ 20: สรุปผลการเรียนรู้จาก Lab (8 ข้อ)

1. เข้าใจขั้นตอนการออกแบบและวิเคราะห์ระบบเว็บแอปพลิเคชันตั้งแต่เริ่มต้น
2. สามารถออกแบบ ER Diagram และสร้างฐานข้อมูล MySQL ด้วย SQL Script ได้
3. สามารถพัฒนา RESTful API ด้วย Node.js และ Express.js
4. เข้าใจการสร้าง User Interface ด้วย React โดยแบ่งเป็น Reusable Components
5. สามารถจัดการ State และ Lifecycle ใน React ด้วย React Hooks
6. สามารถเชื่อมต่อ Frontend กับ Backend API ผ่าน Fetch API
7. เข้าใจการตรวจสอบความถูกต้องของข้อมูล (Form Validation) ทั้ง Client และ Server
8. ได้เรียนรู้กระบวนการทดสอบระบบ (System Testing) และการเตรียมพร้อมไฟล์โปรเจกต์ส่งมอบ
